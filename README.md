# 🍅 TomatoSentinel

## AI-Based Tomato Leaf Disease Detection System

TomatoSentinel is an AI-powered web application developed using Flask and TensorFlow that detects tomato leaf diseases from uploaded images using a trained deep learning model.

---

## Features

- AI-powered disease detection
- Image upload interface
- Confidence score prediction
- Modern responsive UI
- Flask backend
- TensorFlow CNN model
- Real-time disease prediction

---

## Disease Classes

- Bacterial Spot
- Early Blight
- Healthy
- Late Blight
- Leaf Mold
- Septoria Leaf Spot
